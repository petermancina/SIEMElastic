<h2>Dashboard Description</h2>
This Elastic SIEM dashboard provides an at-a-glance view of VPN activity and potential security events. It visualizes VPN traffic by country, highlights top IP addresses and connection counts, summarizes failed login attempts, and lists recent VPN connections with source and destination details. I created this dashboard as part of the Google Cybersecurity Professional Certificate - it demonstrates how SIEM visualizations can help analysts monitor network activity and investigate unusual access patterns.
